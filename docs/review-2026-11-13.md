## 2. ที่ทำได้ดีแล้ว (ไม่ต้องแตะ)

- session หลายแท็บ, กู้แท็บเดิม, ตั้งชื่อ/ลบ session ได้ ปลอดภัย (ตรวจ path ก่อน unlink)
- approval dialog ก่อน bash/edit/write + โหมด "ไม่ถามแล้ว" ที่รีเซ็ตได้
- error banner ที่บอกเหตุจริง (`ads_required`, `concurrent_session`, เครดิตหมด…)
- i18n EN/TH ครบพอใช้, ฟอนต์ Noto Sans Thai ในสแตก
- ระบบ ads ตรงสเปก backend (`x-turn-id`, impression, Gravity pixel) — ตัวที่ทำให้แอปไม่ตายเงียบ
- `scrollToBottom` ไม่แย่ง scrollbar เวลาเลื่อนขึ้นไปอ่าน (เช็คระยะ 180px) — ดีกว่าแอปส่วนใหญ่
- CSP, contextIsolation, token ไม่หลุดเข้า renderer

## 3. ลำดับที่แนะนำให้ทำ (คุ้มที่สุดก่อน)

1. **Markdown + ไฮไลต์โค้ด + ปุ่มคัดลอก** (P1-7,8) — เปลี่ยนความรู้สึกทั้งแอป, ทำในตัว renderer ได้ ไม่ต้องเพิ่ม dependency (เขียน mini-renderer)
2. **เอาชื่อฝังออก + แสดงรุ่น + single instance** (P0-1,4,5) — 3 อย่างนี้ทำให้ "ส่งให้คนอื่น" ใช้ได้จริง
3. **ขนาดตัวอักษรขั้นต่ำ 12px + แก้แถว usage ที่ล้น + เปลี่ยนคำ "เครดิต"→"โควตาวันนี้"** (P2-21,22,23)
4. **@ไฟล์ + `!` shell + /undo** (P1-9,10,12) — สามอย่างที่ทำให้เร็วแบบ opencode
5. **todo + ask_user ลงทะเบียนใน tools** (P1-18) — ต้นทุนต่ำ แต่เห็นความคืบหน้าทันที
6. ต่อด้วย diff review panel, MCP, auto-update ตามลำดับ
