# ปุ่มย่อโมเดลและการ์ด llama.cpp — แบบย่อ

- **เป้าหมาย:** ให้ย่อกลุ่มโมเดลที่เปิดอยู่ทั้งหมดได้ในคลิกเดียว และทำให้ผู้ใช้เข้าใจว่า llama.cpp ใช้เครื่องของตนเอง
- **แนวทาง:** เพิ่มปุ่ม “ย่อทั้งหมด” ในแถบค้นหารายการโมเดลและใช้ state/persistence ของกลุ่มเดิม; ย้ายการ์ด llama.cpp ไปไว้ก่อนตาราง provider จัดโลโก้ซ้าย รายละเอียดขวา พร้อมนำไทล์ llama.cpp ออกจาก grid
- **ไม่ทำ:** เปลี่ยนพฤติกรรมเลือกโมเดล/ติดตั้งเดิม เพิ่มตัวเลือกหรือการตั้งค่าใหม่
- **ทางเลือก:** คงไทล์พร้อมทำการ์ดซ้ำ (ทำให้มีจุดซ้ำ) หรือเพิ่มปุ่ม global โดยไม่แตะระบบพับเดิม (ขัดกับการจำสถานะ); เลือกใช้ระบบเดิมและย้ายการ์ดครั้งเดียว
- **ข้อจำกัด:** รักษาการแก้ไขที่มีอยู่ใน working tree, ไม่เพิ่ม dependency/ไม่ bump เวอร์ชัน, เทสต์ตามสคริปต์ UI เดิมและตรวจสระอำ
