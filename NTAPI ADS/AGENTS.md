## กติกาเหล็ก (เหมือน NTAPI ทุกข้อ — สรุปเฉพาะที่ต่าง)
- **ทุกคำสั่ง shell ต้องมี `timeout`** เริ่ม 120 วินาที เพิ่มเมื่อโดนตัด
- **ห้าม commit / push / tag เอง** — ผู้ใช้ใช้ GitHub Desktop
- commit message = ภาษาไทย กระบาดบรรทัดเดียว
- **ห้ามขยับเลขเวอร์ชันเอง** (`package.json` ของโฟลเดอร์นี้ — ปัจจุบัน `0.1.0`)
  · กฎการขยับ: **`+0.0.1` ทุกครั้งที่ผู้ใช้สั่ง** (แก้กี่เรื่องก็ขยับ 1 ขั้น)
  · ปัญหาใหญ่จริง ๆ (ข้อมูลเสียหาย/ความปลอดภัย/ใช้งานไม่ได้) → **แนะนำได้ ห้ามเลือกเอง**
- **ห้าม commit ไฟล์ที่มี token** — token เก็บที่ `%APPDATA%/ntapi-ads/ads-config.json`
  (นอก repo) อยู่ใน userData ของ Electron เท่านั้น
- repo ปลายทาง **ต้องเป็น public** (`Cheumklang/NTAPI-sponsor`) ไม่งั้น NTAPI ดึงไม่ได้

## โปรแกรมนี้แก้แล้วต้องดูอีกโปรแกรมด้วย
`sponsor.json` คือสัญญาระหว่างสองโปรแกรม:
- ผู้ผลิตฟิลด์: `src/feed.js` (ที่นี่)
- ผู้อ่านฟิลด์: `../app/src/sponsor.js` (`readFeed` / `normalizeSlot`)
- **แก้ชื่อฟิลด์ที่หนึ่ง ต้องแก้อีกที่ใน commit เดียวกัน** ไม่งั้น NTAPI
  จะซ่อนแถบสปอนเซอร์ทันที (slot ที่ผิดรูปถูกทิ้ง ไม่แสดงครึ่ง ๆ)

## เทสต์
```bash
cd "NTAPI ADS"
npm test            # ออฟไลน์: node --check ทุกไฟล์ + 4 selftest
npm run check:render # เปิด Electron จริง ตรวจ DOM/preview/การลากวาง (25 ข้อ)
```
- เพิ่ม `selftest-*.js` ใหม่ → **ต้องลงทะเบียนใน `TESTS` ของ `scripts/run-unit-tests.js`**
- `check:render` ใช้ IPC ปลอม (ไม่ต้องมี token/เน็ต) — ใช้ทดสอบ path ของการครอปจริง
